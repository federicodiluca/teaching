Prompt dei comandi di Windows: esercitazione

Il computer a righe di comando

Prima delle finestre c'era il prompt: scrivi un comando, il computer risponde. Qui ne usate uno simulato, che non tocca i file del vostro computer.

  1. Prompt libero: provate i comandi come in un vero cmd.
  2. Missioni: nove compiti da risolvere scrivendo i comandi giusti.
  3. Che comando è?: smistate i comandi per funzione.
  4. Allenatore: domande su comandi e percorsi.
  5. Caccia all'errore: trovate il comando che non funziona.
  6. Missione finale: dieci domande miste a tempo.

Prerequisito: i percorsi assoluti e relativi (esercizi qui). Il prompt mostra sempre la cartella corrente prima del segno >.

Si gioca da soli, quando e quanto volete. Ogni gioco vi dice subito se avete sbagliato: tenete aperte le slide per consultarle.

1. Prompt libero

Fate pratica: provate dir, cd, tree /f, mkdir... La freccia su richiama il comando precedente.

dirmostra il contenuto della cartella corrente
cd cartellaentra in una cartella (cd .. sale, cd \ va alla radice)
tree /falbero delle cartelle, con i file
mkdir nomecrea una cartella (anche md)
rd nomeelimina una cartella vuota (rd /s anche piena)
copy file destinazionecopia un file
move file destinazionesposta un file o una cartella
ren file nuovorinomina
del fileelimina un file
type filemostra il testo di un file
cls, helppulisce lo schermo, elenca i comandi

2. Missioni

Ogni missione ricomincia da un albero nuovo. Appena il compito è svolto, compare il segno di spunta.

3. Che comando è?

Toccate un comando e poi il gruppo a cui appartiene.

4. Allenatore

Scegliete il tipo e il livello.

5. Caccia all'errore

Tre comandi per fare la stessa cosa: uno solo non funziona. Quale?

Missione finale

Dieci domande miste. Il tempo parte con il primo clic. Ogni domanda vale 1 punto se giusta al primo controllo.
